<Paragraph>
Let's see how far we can go with something we use in almost every dashboard: <Highlight>containers</Highlight>.
</Paragraph>

<Paragraph>
In this blog post, we'll break down <Highlight>how horizontal and vertical containers distribute space in Tableau</Highlight>, how they can be nested, and how this simple idea can be used creatively.
</Paragraph>

<Paragraph>
By the end, we'll put it all together to build the <Highlight>flag of Finland</Highlight>, and once you understand the technique, you can use the same approach to recreate almost any flag made up of rectangular blocks.
</Paragraph>

<Paragraph>
Before we build let's answer few questions.
</Paragraph>

<H1>What are Containers?</H1>

<Paragraph>
A Tableau dashboard is essentially a space where different <Highlight>objects</Highlight> live together. Containers help us control <Highlight>how those objects are arranged within that space</Highlight>. 
</Paragraph>

<Paragraph>
In Tableau, we mainly work with two types of containers:
</Paragraph>

<NumberList items={[
    "Horizontal Container",
    "Vertical Container"
]}/>


<Figure src={ObjectPanel} caption='Horizontal and Vertical containers in Tableau’s dashboard Objects pane'/>

<H2>Horizontal Container</H2>

<Paragraph>
A horizontal container in Tableau allows us to align dashboard objects like charts, filters, text and even more containers <Highlight>side by side in a single row</Highlight>.
</Paragraph>

<Figure src={HorizontalContainer} caption='A horizontal container with three nested horizontal containers, illustrating the left-to-right layout direction'/>

<H2>Vertical Container</H2>

<Paragraph>
A vertical container places dashboard objects one below another, creating a <Highlight>top-to-bottom</Highlight> layout.
</Paragraph>

<Figure src={VerticalContainer} caption='A vertical container with three nested vertical containers, illustrating the top-to-bottom layout direction'/>

<H1>Equal Space or Your Own Rules?</H1>

<Paragraph>
Not every layout needs to share space equally.
</Paragraph>

<Paragraph>
Sometimes we want Tableau to keep things <Highlight>even</Highlight>, and sometimes, we need to decide exactly how much space each object gets.
</Paragraph>

<H2>Let Tableau Share the Space</H2>

<Paragraph>
When <Highlight>Distribute Contents Evenly</Highlight> is enabled, the objects inside the container share the available space equally.
</Paragraph>

<Figure src={DistributeEvenly} caption='A vertical container evenly distributing space using Distribute Contents Evenly'/>
<H2>Or... Let's Break the Balance</H2>

<Paragraph>
Turn it off, and we can take control of the proportions ourselves.
</Paragraph>

<Figure src={DistributeUnevenly} caption='A vertical container with unevenly distributed contents, allowing manual control over the space between each section'/>

<Paragraph>
Now we can adjust the <Highlight>width</Highlight> if it is a horizontal container or <Highlight>height</Highlight> if it is a vertical container of each object to create the layout we want. 
</Paragraph>

<H1>When One Container Isn't Enough</H1>

<Paragraph>
So far, we've been working with one container at a time. But what if we need <Highlight>different layouts within a single layout?</Highlight>
</Paragraph>

<Paragraph>
That's where <Highlight>nested containers</Highlight> come in. We can place one container inside another, giving us more control over how our layout is arranged.
</Paragraph>

<Paragraph>
Think of it as a container inside a container.
</Paragraph>

<H1>And Now, Let's Put It All Together</H1>

<Paragraph>
We’ve looked at horizontal and vertical containers, distribution, and nesting. 
</Paragraph>

<Paragraph>
By combining these simple ideas, we can create something surprisingly creative, flags from around the world, built entirely with Tableau containers.
</Paragraph>

<H1>Let's Build One - Finland Flag</H1>

<Paragraph>
We've talked about what containers can do. Now we'll put everything together to build the <Highlight>flag of Finland</Highlight>.
</Paragraph>

<H2>Dimension of the Flag</H2>

<Paragraph>
The <Highlight>Finnish flag</Highlight> has an overall width-to-height ratio of <Highlight>18:11</Highlight>.
</Paragraph>

<Paragraph>
The <Highlight>width</Highlight> is divided into three sections with a ratio of <Highlight>5:3:10</Highlight>. The <Highlight>height</Highlight> is divided into three sections with a ratio of <Highlight>4:3:4</Highlight>.
</Paragraph>

<Figure src={FinnishFlagDimensions} caption='The Finnish flag with its official proportions and dimensions. The width-to-height ratio of 18:11'/>

<Paragraph>
To maintain the <Highlight>18:11</Highlight> aspect ratio and to make calculations of the strips easier, we'll use a width of <Highlight>900</Highlight> and a height of <Highlight>550</Highlight> pixels.
</Paragraph>

<Panel type='info'>
Throughout the construction process, we will keep Distribute Contents Evenly <Highlight>disabled</Highlight> for all containers.
</Panel>

<H2>Colours Hex Codes</H2>

<Paragraph>
The Finnish flag uses two main colours: pure white <Highlight>#FFFFFF</Highlight> and a deep blue <Highlight>#002F6C</Highlight>.
</Paragraph>

<H2>01 — Start With the Foundation</H2>

<Paragraph>
First, we add a <Highlight>horizontal container</Highlight> as our main container.
</Paragraph>

<Paragraph>
Think of it as the frame that will hold everything together.
</Paragraph>

<Paragraph>
It gives us the basic left-to-right structure we need for the Finnish flag.
</Paragraph>

<Figure src={FirstStep} caption='A 900 × 550 pixels empty horizontal container serving as the main base for the Finnish flag'/>

<H2>02 — Divide the Flag Into Three </H2>

<Paragraph>
Inside the main horizontal container, we add <Highlight>three vertical containers</Highlight> to create the <Highlight>left</Highlight>,
<Highlight>middle blue</Highlight>, and <Highlight>right</Highlight> sections of the flag.
</Paragraph>

<Paragraph>
The reason we chose a <Highlight>900px</Highlight> width becomes clear here. 
We need to divide the width in a 5:3:10 ratio, and 900px fits this proportion perfectly, giving us <Highlight>250px</Highlight>, 
<Highlight>150px</Highlight> and <Highlight>500px</Highlight> for the three sections.
</Paragraph>

<Paragraph>
We’ll set the background colour of each container to match the corresponding colours of the Finnish flag.
</Paragraph>

<Figure src={SecondStep} caption='The main horizontal container divided into three sections to create the blue and white strips of the Finnish flag'/>

<Paragraph>
Now we have the basic skeleton of our cross.
</Paragraph>

<H2>03 — Build the Left Section</H2>

<Paragraph>
Now let's work on the left side of the flag.
</Paragraph>

<Paragraph>
We start with a first vertical container and nest <Highlight>three more vertical containers</Highlight> inside it.
</Paragraph>

<Paragraph>
Each container represents one section of the Finnish flag.
</Paragraph>

<Paragraph>
<Highlight>Top</Highlight>&nbsp;&rarr; White

<Highlight>Middle</Highlight>&nbsp;&rarr; Blue

<Highlight>Bottom</Highlight>&nbsp;&rarr; White
</Paragraph>

<Paragraph>
Again, the reason for choosing a <Highlight>550px</Highlight> height comes in handy here.
We need to divide the height in a 4:3:4 ratio, and 550px fits this proportion perfectly, giving us <Highlight>200px</Highlight>,
<Highlight>150px</Highlight> and <Highlight>200px</Highlight> for the three sections.
</Paragraph>

<Figure src={ThirdStep} caption='A left vertical container divided into three sections white, blue, and white'/>

<Paragraph>
By stacking these three containers vertically, we create the left side of the flag and establish the proportions we need for the cross. 
</Paragraph>

<H2>04 — Mirror the Structure</H2>

<Paragraph>
Now we repeat the same idea on the right.
</Paragraph>

<Paragraph>
In the last vertical container, we’ll nest <Highlight>three more vertical containers</Highlight> inside it.
</Paragraph>

<Paragraph>
Now both sides have their own three-part structure, leaving the middle blue container to complete the cross.
</Paragraph>

<Figure src={ForthStep} caption='The most right vertical container divided into three sections white, blue, and white'/>

<Paragraph>
The nested containers control the details inside the left and right sections, while the middle container creates the blue vertical strip.
</Paragraph>

<Paragraph>
<Highlight>That's it</Highlight>.
This is our Finnish flag. No images, no custom shapes, just a set of nested containers with background colors.
</Paragraph>

</Paragraph>

<Paragraph>

we can turn those simple building blocks into something much more creative.
